# Getting help

ORCHER is a developer preview. The SDKs are open source; the engine image
`ghcr.io/orcher-io/orcher` is free to use for development and evaluation, and
production use requires permission from the maintainers through the
[orcher-io](https://github.com/orcher-io) GitHub organization. APIs can still
change between minor versions, and support is best effort.

- **Questions and how-to:** ask in
  [Discussions](https://github.com/orcher-io/quickstart/discussions) (the
  [Q&A](https://github.com/orcher-io/quickstart/discussions/categories/q-a)
  category). Ideas and things you built are welcome there too.
- **Bugs:** open an issue in the repository of the component that misbehaves,
  using the bug report form. If you are not sure which one, use
  [orcher-io/quickstart](https://github.com/orcher-io/quickstart/issues/new/choose).
- **Feature requests:** open an issue with the feature request form, or start
  with a thread in [Ideas](https://github.com/orcher-io/quickstart/discussions/categories/ideas).
- **Security problems:** do not open an issue; follow the
  [security policy](https://github.com/orcher-io/.github/blob/main/SECURITY.md).

To get started, follow the [quickstart](https://github.com/orcher-io/quickstart).
